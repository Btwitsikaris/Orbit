Open Orbit
# run Orbit (Node 22 or newer)
$ npm start

# open it, then create the first account (it becomes admin)
http://localhost:3000/app

# or with Docker
$ docker build -t orbit . && docker run -p 3000:3000 -v orbit-data:/app/data orbit
